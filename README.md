# C++ Mini Projects

A collection of beginner C++ mini-projects — games, calculators, and algorithms built while learning the language. Each file is a standalone program with its own `main()`.

## Projects

| Project | File | Concepts Practiced |
|---|---|---|
| 🎲 Number Guessing Game | `number_guessing_game.cpp` | `rand()`/`srand()`, `do-while` loops, conditionals |
| 🖩 Console Calculator | `calculator.cpp` | `switch` statements, arithmetic operators, user input |
| 🏦 Banking Console | `banking_console.cpp` | Functions, global state, menu-driven `do-while` loop |
| ✊✋✌️ Rock, Paper, Scissors | `rock_paper_scissors.cpp` | Functions returning values, random choice logic |
| 📝 Quiz Game | `quiz_game.cpp` | Parallel arrays, loops, string comparison, score accumulator |
| 💳 Credit Card Validator | `credit_card.cpp` | Luhn Algorithm, string-to-digit conversion, boolean toggling |
| 🔤 Word with Most Vowels | `vowel_counter.cpp` | Function decomposition, string traversal, "find the max" pattern |

## How to Run

Each file is self-contained. Compile and run individually with g++:

```bash
g++ number_guessing_game.cpp -o game
./game
```

(Replace the filename with whichever project you'd like to run.)

## About

These projects were built while learning C++ fundamentals — control flow, loops, functions, arrays, strings, and basic algorithmic thinking. Each one focuses on applying a specific set of concepts in a small, complete program.
